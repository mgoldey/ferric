# Sizing: analytic Hessian with smeared external charges (#358) and ECPs (#285)

Facts measured on the dev box (libint 2.13.1 source build and the 2.7.2 "small" wheel export); probes in `probes/`, tests in `crates/ferric-integrals/tests/{smeared_deriv2_stencil,ecp_second_derivative_stencil}.rs`.

## #358 facts
- Source build 2.13.1: `LIBINT2_DERIV_ERI3_ORDER 2`, `LIBINT_ERI3_MAX_AM_LIST "7,7,4"`; effective limit l <= 3 (max_l = 4 with deriv 2 throws `lmax_exceeded`). Wheel 2.7.2 small export: `LIBINT2_DERIV_ERI3_ORDER 1`; a 3-centre deriv-2 engine compiles and aborts on first use ("null build function ptr"). The shim guard (`shim.cc:1294`, `LIBINT2_MAX_DERIV_ORDER >= 1`) cannot detect this; a new entry would need `LIBINT2_DERIV_ERI3_ORDER >= 2`.
- One-body `erf_nuclear` with omega = sqrt(zeta) equals `(mu nu|g)/norm` to 1e-16 on 2.13.1 and its deriv-1/2 agree with central differences to ~1e-9 (l <= 3); on 2.7.2 it is WRONG (e.g. (0,0): -0.3793 vs -0.2913) with self-consistent derivatives, so any version gate must check the value. ferric has no wiring for it (`op_for_kind`, `shim.cc:366-380`).
- Stencil (4th order, h = 2e-3) of the analytic first-derivative blocks vs Richardson mixed second differences of the value blocks, water/cc-pVDZ, one site 2.1 Bohr away: max abs diff 7.2e-10 (w = 1.2), 2.0e-11 (w = 0.14), 4.3e-13 (w = 0.01). vs libint's own analytic second derivatives: 8.8e-12 (l = 2,1), 9.3e-11 (l = 3,3); error falls as h^4.
- Hook points: attraction `oneelectron.rs:159-205`; gradient `gradient.rs:1444-1520`; refusal `hessian.rs:539-543` (scope text `:69`); `contract_external_deriv2` (`hessian.rs:891`), `first_order_ao` (`:1069`), stencil precedent `hessian_field.rs`; classical term `charge_nuclear_hessian` (`external_potential.rs:177`) is point charges only. Tests asserting the refusal that must change: `qmmm_hessian_fd.rs:218`, `frequency_hessian_dispatch.rs:100-114`, `saddle_analytic_hessian.rs:230-233`.
- Sub-tasks: (1) smeared branch of `charge_nuclear_hessian`, `E = Z q erf(R/w)/R`, `f'' = -(2/(sqrt(pi) w)) e^{-R^2/w^2}(2/w^2 + 2/R^2) + 2 erf(R/w)/R^3`, block `Zq[f'' d d^T/R^2 + (f'/R)(I - d d^T/R^2)]`, anchored by FD of `charge_nuclear_gradient`; (2) `dV/dx` AO matrices into `F^x`; (3) skeleton `sum D d2V` stencil module; (4) remove the refusal, update scope doc and the three tests, keep the Thole polarizable path refused; (5) validate: empty smeared charges bit-identical, zeta = 1e6 limit vs #343, FD of the analytic smeared gradient (floor ~5e-6), FD of PySCF `mm_charge(radii=)`, mutants (drop smeared nuclear term, drop `dV/dx` from `F^x`, shift single shells instead of atoms).

## #285 facts
- Default ECP backend is ferric's `ecp_quad` (`ecp.rs:10-18, 77-108`, `FERRIC_ECP_BACKEND`); `ecp_potential_deriv` (`oneelectron.rs:364`) follows it. ECP adds two Hessian terms: skeleton `sum D d2V_ECP` (`skeleton_hess_1e`, `hessian.rs:861`) and `dV_ECP/dx` in `F^x` (`first_order_ao`, `:1069`). Refusal: `system_refusal`, `hessian.rs:574-578`. 4-centre second derivatives stop at f in every libint build here, so def2-SVP/TZVP and (aug-)cc-pVDZ/TZ-PP are in, g-shell bases are out.
- libecpint has `compute_second_derivs` (`api.hpp:168-192`, `api.cpp:283-420`, needs `init(2)`; ferric wraps only first derivatives, `ecp_shim.cc:151-199`), but HI/def2-SVP: analytic second derivatives vs the stencil of its own first derivatives differ by 7.9e-6 on a max element of 5.6 (1.1-1.6e-6 relative), step-independent, i.e. systematic.
- ecp_quad stencil, H-I-H/def2-SVP, all atom pairs: |S(h) - S(2h)| = 7.8e-10 (max element 2.05); the same test on the libecpint backend is 2.4e-8 (31x worse).
- PySCF has an ECP Hessian and it matches FD of its own analytic gradient to 4.6e-6 (HI/def2-SVP, step 1e-3; HBr control 4.8e-6; translational sum 6e-12); integrals `ECPscalar_ipipnuc`, `ipnucip`, `ipiprinv`, `iprinvip` exist (`pyscf/hessian/rhf.py:249-250, 505-540`).
- Sub-tasks: (1) `ecp_potential_deriv2_contract(mol, bs, D) -> 3N x 3N` as a masked stencil added to `skeleton_hess_1e`; (2) `ecp_potential_deriv` matrices into `h1` in `first_order_ao` for RHF and UHF; (3) remove the ECP refusal, keep the atom-count guard, typed error for l > 3; (4) PySCF generator, validate on HI, CH3I, Ag2/aug-cc-pVDZ-PP and one UHF case, checking the skeleton via `ECPscalar_ipip*` first; (5) anchors: no-ECP bit-identical, row sums <= 1e-10, stencil step sweep, a negative control (dropping the skeleton must miss PySCF by > 10x the bar), mutants (wrong atom in the ECP-centre fold, `dV/dx` missing from `F^x`). Upgrade path: analytic second derivatives in `ecp_quad` by raised/lowered shells (M-L).
