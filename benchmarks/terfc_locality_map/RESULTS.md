# terfc locality map: results (2026-10-10)

Pre-registration: `locality_map_prereg.md` (committed before any production number).
Harness: `crates/ferric-mp2/tests/terfc_locality_map.rs` (ignored). Analysis:
`analyze.py`, `md_table.py`, `trend.py`. Alkanes C8/C10/C12 (testdata/molecules),
6-31G / cc-pvdz-ri, frozen core = N carbons, Coulomb RHF reference, attenuated
correlation operator, amplitude-threshold LMP2 with TRIVIAL maps (aux_radius 1e6,
no virt radius, ao_tail 0, schwarz_skip 0): the only truncation is the amplitude
mask. relerr(eps) = |E(eps) - E(0)| / |E(0)| with E(0) the same operator's eps=0
`ri_mp2` value; eps* by log-log interpolation. Box shared, load 9-23 throughout.

## Gates passed before any sweep

* Exactness anchor: direct/dense eps=0 vs same-operator `ri_mp2`, 22 operator rows
  on C8 (incl. soft seams and r0 10 A): |d| <= 2.8e-13 Ha (bar 1e-9).
  Sensitivity of the bar: r0*omega = 0.7071 vs 0.70710678 (a 1e-5 relative
  operator change) moves E(0) by 9.2e-7 Ha, 900x over the bar.
* Cheap path vs production path: `amplitude_lmp2` (global 3-index; used for all
  sweeps) vs `amplitude_lmp2_direct` (trivial maps), C8 eps=1e-3, Coulomb and
  terfc linked: e_corr, keep, pairs, dom_mean identical in every printed digit
  (-0.7075196850 / -0.6804742404). ~40x cheaper for terfc (direct 230 s vs dense
  6 s per eps). Not re-checked at C10/C12 or at other operators.
* Null control: terfc r0 = 10 A, r0*omega = 4 (kernel ~ Coulomb over the molecule):
  E/E_Coul = 0.9999, keep 18.25 vs 18.46 %, eps* 4.92e-5 vs 4.88e-5, pairs 625 vs
  620, dom 73.8 vs 73.0. PASS (it fails by construction at r0 = 1 A: keep 14.3).
* relerr(eps) monotone in all 36 sweeps. Interpolation check by confirming runs at
  eps*: keep 13.77 vs interpolated 14.26 (terfc 1.0 linked), 6.08 vs 6.45
  (0.5/4): interpolation overstates keep by 3-6 % (concave in log eps). Differences
  between operators below ~8 % are NOT resolved.

## Softer-seam validation (r0*omega < 0.707), done before using those rows

Artifact hypothesis (stated first): if the softer-seam integrals were wrong I
expect a Fourier-check miss >= 1e-6, a non-PD metric, or an energy outside the
Coulomb-bounded range. `scripts/validation/terfc_omega_fourier_check.py`
(PySCF ft_ao + k-space quadrature, shares no code with the MD/table engine;
extended to take per-case r0; dump test extended via FERRIC_DUMP_CASES), water
cc-pVDZ / cc-pVDZ-RI, 3-rung grid ladder:

| 0.5 | 0.35, 0.7071, 4 | 1.7e-13 | 3.7e-13 | 5.1e-4, 4.8e-4, 4.8e-4 |
| 0.7 | 0.35, 2 | 1.7e-13 | 4.7e-13 | 5.2e-4 |
| 1.35 | 0.35, 0.7071, 4 | 1.8e-12 | 7.2e-12 | 5.1e-4 - 5.4e-4 |

erf anchor at each omega <= 1e-13; k-space self-change shrinks across the ladder.
PD in all cases. The kernel terfc(r) = 1 - [erf(w(r-r0)) + erf(w(r+r0))]/2 lies in
[0,1], so terfc/r <= 1/r pointwise for EVERY (r0, omega). The energy bound
|E_att| <= |E_Coul| (Dutoi/linked invariant) holds at r0*omega = 0.35 (0.81-0.99)
and linked (0.63-0.99) but FAILS for r0*omega >= 2 (1.18-1.99; MP2 is quadratic in
the kernel; k-space overshoot, as already known). Softer seams therefore PASS and
are included. Scope: one small molecule (nao 24, naux 84): the s = (phi r0)^2 range
it samples is set by that basis's exponents, so very tight aux functions on heavier
atoms are not covered. Cases with r0*omega in (0.35, 0.707) other than 0.5 and in
(0.707, 2) not validated (not used).

## Erratum to the pre-registration (physics, not data)

The prereg said a SOFTER seam should be more local. That was wrong physics
reasoning, found when tabulating the real-space kernel: the seam half-width is
1/omega, so a softer seam has a LONGER tail. Distance at which terfc falls to 0.1,
r0 = 1.0 A: 3.71 A (r0*omega 0.35), 2.28 (linked), 1.45 (2), 1.23 (4); the sharp
limit is a step at r0. The prereg's core (range/tail controls locality) predicts the
opposite sign for omega from what its softer-seam sentence said. The data below
follow the core claim. The prereg file is left unedited.

## What sets locality at matched relative error (H1 vs H2)

20 terfc/erfc operators on C8 (Coulomb and the null control excluded), keep %
at relerr 1e-3 / 1e-2:

* Spearman rho vs R(0.1) (kernel range): 0.92 / 0.94 (log-log Pearson 0.92 / 0.91)
* Spearman rho vs E_att/E_Coulomb (the energy-scale artifact): 0.49 / 0.52

So at matched RELATIVE error the correlation-energy scale is NOT what orders the
operators; the kernel range is. H2 (gain = shrinking energy scale) is refuted as
the main explanation. Caveats: 20 operators from one molecule are not independent
(4 r0 x 5 omega variants plus erfc); R(0.01) gives rho 0.87 / 0.89; R(0.5) not
tested. Outliers sit ABOVE the range curve, all at r0*omega >= 2 with r0 >= 1.0:
terfc 1.0/4 (R(0.1) 1.23 A, keep 14.8 % vs ~9.5 % for erfc w=1.0, R(0.1) 1.16 A),
1.35/4 and 1.35/2. Hypothesis (not tested): the step discontinuity at r0 leaves an
oscillatory k-space tail that the range descriptor does not see.

The fixed-absolute-eps comparison was nearly matched already: eps* for relerr 1e-3
is 4.4e-5 - 9.6e-5 for every operator (E/E_Coul 0.31 - 1.99), within 2.2x; sharper
seams need a LARGER eps (their E(0) is larger).

## MP2-V implications (r0 vs the paper's valley)

Paper (JCTC 11, 4159): MP2-V(terfc, aTZ) r0 = 0.85-1.10 A with b = 8.0-14.5 (Table
1; text: "approximately 0.8 to 1.2 A viable"); SCS-MP2-V(2terfc): r0 SR 0.70 A, MR
0.90 A, b = 14.0. EVERY paper number uses the curvature-linked omega, so any
decoupled omega is off the published surface regardless of r0.

| operator (r0 A, r0*omega) | r0 in viable 0.85-1.10 | keep % vs linked-1.0 (C8) | E_att/E_Coul | flag |
|---|---|---|---|---|
| 1.0, 0.7071 | yes (the paper) | 1.00 | 0.96 | reference |
| 1.0, 0.35 | yes | 1.15 (worse) | 0.97 | no locality reason |
| 1.0, 2 | yes | 0.79 | 1.58 | in-range candidate; E_att > E_Coul, VV10 b must compensate overbinding |
| 1.0, 4 | yes | 1.04 | 1.99 | no gain, E_att = 2x Coulomb |
| 0.7, linked / 4 | no for plain MP2-V; = SCS SR value | 0.80 / 0.52 | 0.84 / 1.37 | refit: VV10 carries more dispersion |
| 0.5, linked / 4 | no (below 0.8) | 0.64 / 0.45 | 0.63 / 0.68 | outside; VV10 half must carry much more |
| 1.35, linked / 4 | no (weak-attenuation side; optimum for MP2(terfc) without VV10) | 1.14 / 0.99 | 0.99 / 1.84 | no locality advantage |

For the refit agent: inside the viable r0 range the only locality gain from
decoupling is r0*omega ~ 2 at r0 ~ 1.0 (about 20 % fewer amplitudes, 2-3 % fewer
pairs/domain), bought with E_att/E_Coul = 1.58 (the attenuated MP2 then carries MORE
correlation than full MP2, opposite to the design intent behind the long-range limit
and the VV10 handoff). Candidates to test in the fit, not claims: (r0 0.85-1.10,
r0*omega 1-3). Do not fit omega softer for locality.

## Verdict

Relaxing omega UPWARD (sharper) at fixed r0 buys a modest, non-monotone saving in
the amplitude fraction (0.64-0.88x of linked at r0 <= 1.35, but 1.04x at r0 = 1.0,
r0*omega 4), nothing measurable in pair count or domain size at the sizes reached,
costs +15 % per quartet and makes E_att exceed E_Coul. Relaxing omega DOWNWARD
(softer) makes locality WORSE (1.08-1.34x) because the kernel tail lengthens (1/omega).
Locality is ordered by kernel range, which r0 sets more cheaply: r0 1.0 -> 0.5 at
linked omega is 0.64x, larger than any omega move at r0 = 1.0, but r0 < 0.85 is
outside the paper's valley. Against the artifact hypothesis: at matched relative
error the ordering follows kernel range (rho 0.92), not energy scale (rho 0.49), so
the differences are not an eps-scale effect; they are also small (<= 36 % of
amplitudes) next to what eps itself does (Coulomb C8 keep goes 1.3 % -> 11.2 % from
eps 1e-3 -> 1e-4, ~8x), and the fixed-absolute-eps result of the earlier lane (second
digit only) is consistent with this, since eps* for a given relative error is within
2.2x across operators.

## Unverified / limits

* C8-C12 alkanes only, below the onset; 6-31G, not aTZ (diffuse functions would change
  amplitude decay); no 3-D, polar, aromatic systems; pair/domain statements at
  relerr 1e-3 are saturated and uninformative.
* Softer-seam integrals validated only on water/cc-pVDZ(-RI); other r0*omega values
  (0.35-0.707 except 0.5, 0.707-2 except 2) not validated and not used.
* Sweeps use the dense path (identical to direct checked only at C8, 2 operators,
  eps 1e-3). eps* by interpolation (keep +3-6 % bias; two confirming runs only).
