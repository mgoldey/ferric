# 25. Dispersion

Three ways ferric adds long-range dispersion to an energy, from the cheapest
to the most physical: the pairwise D3(BJ) correction fitted per functional,
Casimir–Polder $C_6$ coefficients from dynamic polarizabilities, and
many-body dispersion (MBD@rsSCS), which couples atomic oscillators instead of
summing pairs.

The imaginary frequency is $u$ (chapter 0, section 8). An atom's oscillator
frequency carries an atom subscript, $\omega_A$, as in the code and in
section 27.3; it is never the range-separation parameter, which does not
appear in this chapter.
