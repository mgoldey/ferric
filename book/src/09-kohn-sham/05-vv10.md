# 9.5 VV10 nonlocal correlation

<!-- section: 9.5; status: ready; registry: ks-vv10;
     theory: crates/ferric-dft/theory.md#"VV10 nonlocal correlation" -->

VV10 adds a dispersion-like correlation energy that is a double integral
over the density, with a kernel built from the local density and its
gradient at both points. ferric evaluates it as a double sum over a separate
coarse grid, and gets the per-point potentials from one extra pass over the
same pairs.

| Symbol | Meaning | Code name |
|---|---|---|
| $W_i$, $\rho_i$, $\sigma_i$ | weight, density, $\lvert\nabla\rho\rvert^2$ at point $i$ of the VV10 grid | `grid[g].weight`, `rho`, `sigma` |
| $b$, $C$ | VV10 parameters (from libxc) | `b_vv`, `c_vv` |
| $\omega_0$, $\kappa$, $g$ | local frequency, local scale, $\omega_0R^2 + \kappa$ | `w0`, `kp`, |
| $f_i$, $u_i$, $w_i$ | the three pair sums | `f_g`, `u_g`, `w_g` |
| $\beta$ | the constant per-particle term | `beta` |

| Entry point | Location |
|---|---|
| Rust | `ferric-dft/src/vv10.rs::{compute_vv10_energy_and_potentials,add_vv10_scratch,vv10_internal_screened}` |
| CLI, Python | any VV10 functional (ωB97X-V, ωB97M-V); `[dft] nlc_grid`, `nlc_grid=` |

```rust
let exc_g = beta + 0.5 * f_g;
exc[g] = exc_g;
vrho[g] = beta + f_g + 1.5 * (u_g * dk_dr[g] + w_g * dw0_dr[g]);
vsig[g] = 1.5 * w_g * dw0_dg[g];
e_nl += grid[g].weight * rho[g] * exc_g;
```

| Symbol | Code |
|---|---|
| $\beta + \tfrac12f_i$ | `exc_g` |
| $\rho\,\partial\kappa/\partial\rho$, $\rho\,\partial\omega_0/\partial\rho$, $\rho\,\partial\omega_0/\partial\sigma$ | `dk_dr`, `dw0_dr`, `dw0_dg` |
| $E_{nl}$ | `e_nl` |

## 9.5.2 The algorithm

| Step | What | Cost |
|---|---|---|
| 1 | density, gradient on the VV10 grid (default flat $50\times50$, never pruned) | as section 9.3 |
| 2 | per active point ($\rho \ge 10^{-8}$): $\omega_0$, $\kappa$ and the three $\rho$-scaled derivatives | $O(N)$ |
| 3 | pair sums $f_i$, $u_i$, $w_i$ over partners within 40 Bohr, through a cell list of that edge (dense below `CELL_LIST_MIN_PTS`) | $O(N\cdot N_{\rm near})$ |
| 4 | $E_{nl}$, $v_\rho$, $v_\sigma$ per point | $O(N)$ |
| 5 | $V_{nl}$ in the closed-shell GGA form, added to the Fock matrix (both spins get the same $V_{nl}$ in UKS) | `add_vv10_scratch` |

**Reproducibility and accuracy.** The 40 Bohr cutoff is a fixed constant,
not an option: its error bound (theory section above) is $10^{-8}$ Ha for
systems up to a few hundred atoms. The nuclear gradient of VV10 does not
include the Becke-weight response of the VV10 grid, by design; it depends on
`nlc_grid` and is not FD-validated on its own (validation page, KS gradient
on custom grids).
