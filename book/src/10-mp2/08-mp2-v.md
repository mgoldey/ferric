# 10.8 MP2-V: attenuated MP2 with a VV10 tail

<!-- section: 10.8; status: edit; registry: mp2-v;
     theory: crates/ferric-mp2/theory.md#"13. MP2-V" -->

Attenuated MP2 (section 10.4) has no long-range dispersion. MP2-V adds it
back with the VV10 nonlocal correlation functional, damped at short range
so it does not count again what the attenuated MP2 already holds (Goldey,
Belzunces and Head-Gordon, J. Chem. Theory Comput. 11, 4159 (2015)). With
the tail present the attenuation can be harder: MP2-V uses
$r_0 = 1.00$ Å at aug-cc-pVTZ, where plain attenuated MP2 uses 1.35 Å.

| Entry point | Location |
|---|---|
| Rust | `ferric-mp2/src/att_vv10.rs::att_mp2_vv10` (RHF), `ferric-mp2/src/att_vv10.rs::u_att_mp2_vv10` (UHF, ROHF) |
| CLI | `method.kind = "mp2-v"`, `[mp2] mp2v_r0` (Å), `mp2v_b`, `mp2v_c`, `mp2v_omega` (Å⁻¹), `mp2v_attenuator`, `mp2v_vv10_damping`, `mp2v_nlc_n_radial`, `mp2v_nlc_n_angular` |
| Python | `run_mp2_v(r0=, b=, c=, omega=, attenuator=, vv10_damping=, frozen_core=)`, closed shell; `run_mp2_v_scan` for parameter sweeps |

## 10.8.1 The energy

$$ E_{\text{MP2-V}} = E_{\mathrm{HF}} + E_c^{\mathrm{att}}\big[\operatorname{terfc}(r; r_0)/r\big] + E_{\mathrm{nl}}\big[\rho_{\mathrm{HF}};\, b, C, r_0\big] . \tag{10.19} $$

The first correlation term is section 10.4's terfc RI-MP2 (UMP2 for an
open-shell reference). The second is VV10 on the Hartree–Fock density,
written as a grid sum

$$ E_{\mathrm{nl}} = \sum_g w_g\,\rho_g\Big(\beta + \tfrac12 f_g\Big), \qquad f_g = \sum_{g'} w_{g'}\,\rho_{g'}\,\Phi(g, g')\,d(R_{gg'}), \qquad \beta = \frac{1}{32}\Big(\frac{3}{b^2}\Big)^{3/4} , \tag{10.20} $$

with $\Phi$ the VV10 kernel of Vydrov and Van Voorhis (chapter on VV10 in
`crates/ferric-dft/theory.md`) and the damping

$$ d(R) = 1 - \operatorname{terfc}(R; r_0)^2 . \tag{10.21} $$

The same $r_0$ appears in (10.19) and (10.21); it is one parameter, not two.
$d(0) = 0$ and $d \to 1$ at large $R$, so VV10 contributes where the
attenuated MP2 kernel has died away (the dashed curve in section 10.4's
figure). Only the pair kernel is damped. $\beta$ is a local constant and is
not.

Damping makes $f_g$ less negative, so the absolute $E_{\mathrm{nl}}$ rises.
The dispersion binding is a difference between complex and monomers, not
the sign of the absolute number.

> **Verified equation 10.21** · the MP2-V damping and its cutoff
>
> $d(0) = 0$; $d \to 1$ as $R \to \infty$; beyond
> $r_{\mathrm{one}} = r_0 + 5/\omega$ the computed terfc is below $10^{-12}$
> and $1 - \operatorname{terfc}^2$ rounds to exactly 1.0 in double
> precision, so the code skips the damping there without changing a bit.

## 10.8.2 Parameters

The published method is MP2-V(terfc, aTZ): fitted on S66 at aug-cc-pVTZ,
frozen core, no counterpoise, with the SG-1 grid.

| Parameter | Published | ferric default | Note |
|---|---|---|---|
| $r_0$ | 1.00 Å (1.890 Bohr) | 1.00 Å | `mp2v_r0`, Å |
| $b$ | 11.0 | 11.0 | moves with $r_0$ (table below) |
| $C$ | 0.0089 | 0.0089 | fixed at the LC-VV10 value, not fitted |
| attenuator | terfc | terfc | `"erfc"` is a control, not the method |
| frozen core | yes | CLI and Python: 0 (Rust: 0) | set it; a notice is printed at 0 |
| grid | SG-1 | 50 radial × 50 angular NLC grid | ferric has no SG-1 |
| VV10 in the Fock matrix | optional in the paper | no: post-HF only | the paper reports both as equivalent |

$r_0$ and $b$ are correlated. The paper's fit valley, available as
`AttVv10Config::mp2_v_terfc_atz_at_r0`:

| $r_0$ (Å) | 0.85 | 0.90 | 0.95 | 1.00 | 1.05 | 1.10 |
|---|---|---|---|---|---|---|
| $b$ | 8.0 | 9.0 | 9.5 | 11.0 | 12.5 | 14.5 |

Changing `mp2v_r0` without moving `mp2v_b` leaves the fitted valley.

A free seam width `mp2v_omega` (Å⁻¹) replaces the curvature link in both
the MP2 kernel and the damping together; an $\omega$ set on one and not the
other is an error. Any free-$\omega$ run is unparameterized: $b$ was fitted
at the linked width.

The CLI prints a notice for each departure from the fitted protocol: frozen
core 0 or nonstandard, a basis other than aug-cc-pVTZ, the erfc attenuator,
an open-shell reference.

## 10.8.3 Scope of the parameterization

| Use | Status |
|---|---|
| Closed-shell noncovalent interactions, aug-cc-pVTZ, no counterpoise | the fitted method |
| Other bases | unparameterized; no MP2-V(aDZ) was published |
| Counterpoise-corrected interaction energies | a convention mismatch |
| Open-shell references | unparameterized: S66 is all closed shell |
| Bonded interactions (reaction energies) | not recommended by the paper |

For orientation, the paper reports S66 RMSDs (kcal/mol, aug-cc-pVTZ, no
counterpoise) of 1.533 for MP2, 0.251 for MP2(terfc, aTZ) and 0.199 for
MP2-V(terfc, aTZ), with 0.202 for the post-HF variant ferric runs. These
are the paper's figures, not ferric anchors.

## 10.8.4 What is anchored

| erfc control $E_c$ vs PySCF `with_range_coulomb` RI-MP2 | as above | ≤ 7.0e-12 Ha | 1e-10 Ha | as above |
| $E_{\mathrm{nl}}$ on ferric's own HF density; $\int\rho$ on the NLC grid | | ≤ 1.12e-13 Ha; ≤ 1.10e-13 electrons | 1e-12 | as above |
| Collapsed UHF singlet reproduces the closed-shell values | | terfc $E_c$ ≤ 9e-12 Ha | | as above |

The controls show the test can fail: erfc and Coulomb operators miss the
terfc $E_c$ by at least 1.0e-3 Ha. The implementation is graded Proven
(narrow); the parameterization has no external total-energy anchor because
the paper reports only aggregate statistics. Figures from
`site/src/reference/validation.md`.

## Known limits (2026-11-15)

- Energy only; no gradient and no VV10 term in the Fock matrix.
- Python `run_mp2_v` is closed-shell; open shell is CLI or Rust.
- No SG-1 grid.
