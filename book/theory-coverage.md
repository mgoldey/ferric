## theory.md defects

Recorded earlier by the book rewrite (`00-notation.md#notation-disagreements-between-files-code`,
`book/notation.md` section 10, and section pages):

- `ferric-scf/theory.md:11-12`: $D = \sum_i CC^{\mathsf T}$ without the factor 2 (code builds $2CC^{\mathsf T}$).
- `ferric-mp2/theory.md:38,43,56,65`: stale `rimp2.rs` line references (also `scripts/mp2_variant_identities.py:10-12`).
- `ferric-mp2/theory.md:108-110`: "thesis Eq 5.6" label unchecked (it is the expression at line 103).
- `ferric-core/theory.md:13`: Bohr radius "to 10 digits". The audit found this entry is itself wrong: theory.md has 11 digits, equal to `units.rs`; the book's remark should go.
- `ferric-scf/theory.md` DIIS: sign of $(fn-nf)_{ai}$ (book `08-convergence/01-diis.md#diis-doc-fixes-needed`).
- notation differences only (not defects): tddft $(ia|jb)$, gw $\tilde B$, rpa eigenpotentials, mp2 negative denominator, d3 $\alpha$, mbd tildes, TS $u_A$.

Found by this audit (verified against the code):

- `ferric-scf/theory.md` ROHF effective Fock: "$C^{\mathsf T}SP_c^{\mathsf T}XP_cSC$ is the $cc$ block" has two extra $S$ factors; the code (`roothaan_fock_inner`) and the book use $P_c = D_\beta S$ and $C^{\mathsf T}P_c^{\mathsf T}XP_cC$. Checked with numpy on a random 7-function non-orthogonal model: book form error 3e-15, theory form error 2.0; block table 5e-15.
- `ferric-scf/theory.md` CFMM: spherical-harmonic expansion; `cfmm.rs` uses primitive Cartesian multipoles.
- `ferric-scf/theory.md` Newton: "PCG on $(H+\mu)\kappa=-g$"; `pcg_refine` uses the unshifted residual, $\mu$ only in the preconditioner and $\kappa^0$.
- `ferric-scf/theory.md` RESP: "returns its last iterate after 50 iterations"; the code returns `FerricError::Convergence`.
- `ferric-scf/theory.md` COSMO: $\xi_k$ does not change with geometry (only `swf_k` and positions do).
- `ferric-cc/theory.md` TNOs: "in-span eigenvalues are $\ge 1$" is false for the projector sum (two 1-D subspaces give $1\pm\cos\theta$).
- `ferric-dft/theory.md` VV10 cutoff: bound reaches $10^{-8}$ Ha at $\sum_g w_g\rho_g^{1/4}\approx 21$, not 60.
- `ferric-mp2/theory.md` section 4: `run_terfc_rimp2` r0 is a per-basis table (`resolve_terfc_r0`); 1.05 Å is the aug-cc-pVDZ row only.
- `ferric-export/theory.md` Voxel evaluation: $\sum_P c_P\chi_P$ is the mode charge density, not the eigenpotential.
- `ferric-quadrature/theory.md`: exact dRPA uses 48 points, not only "CLI optimize differs".
- `ferric-core/theory.md`: the elements module has no valency data.
- `ferric-tensors/theory.md`: "BLAS/MKL"; the code is k-blocked ndarray GEMM on OpenBLAS.

Book-side defects found: `14-derivatives/08-geometry-search.md#geometry-search-options` says the QM/MM search refuses `lindh` (the code seeds it from Lindh); `02-molecules-and-numerics/01-molecule.md` Bohr-radius remark (above); `02-molecules-and-numerics/04-tensors.md` cites ferric-tensors theory.md as a source.
